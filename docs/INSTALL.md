# Инструкция по сборке и установке J.A.R.V.I.S. (Android NDK)

Данное руководство описывает процесс клонирования репозитория, компиляции нативных C++ библиотек (`llama.cpp` и `whisper.cpp`) под архитектуру ARM64 и развертывания моделей нейросетей на смартфоне Android.

---

## 1. Системные требования

### Среда разработки (ПК)
* **Android Studio** (актуальная версия с поддержкой Gradle 8/9 и AGP).
* **Android NDK (Side by side)** версии `26.x` или выше.
* **CMake** версии `3.22.1` или выше.
* **Git** (с поддержкой субмодулей).

### Целевое устройство (Смартфон)
* **ОС:** Android 8.0 (API 26) или выше.
* **Архитектура CPU:** строго `arm64-v8a` (64-битный процессор).
* **Оперативная память (RAM):** от 4 ГБ (рекомендуется 6+ ГБ).
* **Свободное место:** ~1.5 ГБ для хранения весов нейросетей.

---

## 2. Клонирование репозитория

Поскольку движки `llama.cpp` и `whisper.cpp` подключены как внешние зависимости, клонировать проект необходимо с флагом `--recursive`:

```bash
git clone --recursive https://github.com
cd JarvisAssistant
```

Если репозиторий уже был склонирован без субмодулей, подгрузите их вручную:
```bash
git submodule update --init --recursive
```

---

## 3. Сборка проекта в Android Studio

1. Откройте папку `JarvisAssistant` в **Android Studio** и дождитесь завершения синхронизации Gradle.
2. **Важно для производительности:** Переключите вариант сборки с `debug` на **`release`** (вкладка *Build Variants* в левом нижнем углу). В релизной сборке активируются флаги оптимизации компилятора C++ (`-O3 -DNDEBUG`), что ускоряет генерацию токенов в 10–15 раз.
3. Подключите смартфон с включенной **Отладкой по USB** (или по Wi-Fi) и нажмите **Run (`▶`)**, либо соберите установочный файл через меню **Build → Generate App Bundles or APKs → Generate APKs**.

---

## 4. Скачивание и установка моделей нейросетей

Файлы весов не включены в Git-репозиторий из-за ограничений на размер файлов. Их необходимо скачать с платформы **Hugging Face** и поместить в рабочую директорию приложения на смартфоне.

### Шаг 4.1. Загрузка файлов на ПК
1. **Модель распознавания речи (Whisper):**
    * Репозиторий: `ggerganov/whisper.cpp`
    * Скачайте **`ggml-base.bin`** (~142 МБ, рекомендуется для качественного распознавания русского языка) или **`ggml-tiny.bin`** (~75 МБ, для максимальной скорости).
2. **Языковая модель (LLM):**
    * Репозиторий: `Qwen/Qwen2.5-1.5B-Instruct-GGUF`
    * Скачайте файл `qwen2.5-1.5b-instruct-q4_k_m.gguf` (~1.1 ГБ).
    * Переименуйте файл строго с учетом регистра в **`Qwen2.5-1.5B-Instruct-Q4_K_M.gguf`**.

### Шаг 4.2. Копирование в память смартфона
1. Запустите установленное приложение **JarvisAssistant** на телефоне один раз, чтобы система создала для него директорию во внутренней памяти, после чего полностью закройте приложение.
2. Скопируйте оба файла в папку `/sdcard/Android/data/com.portfolio.jarvis/files/` с помощью утилиты `adb` (указывая точное имя файла в конце пути):

```bash
adb push ggml-base.bin /sdcard/Android/data/com.portfolio.jarvis/files/ggml-base.bin
adb push Qwen2.5-1.5B-Instruct-Q4_K_M.gguf /sdcard/Android/data/com.portfolio.jarvis/files/Qwen2.5-1.5B-Instruct-Q4_K_M.gguf
```

---

## 5. Первый запуск и настройка голоса

1. Запустите **JarvisAssistant** на смартфоне и предоставьте разрешение на использование **микрофона**.
2. Дождитесь окончания загрузки моделей в ОЗУ (3–5 секунд) — дуговой реактор загорится голубым светом.
3. **Примечание для устройств Huawei / Honor (EMUI / HarmonyOS):** Если приложение выводит текст, но не озвучивает ответы, перейдите в *Настройки → Специальные возможности → Синтез речи* и убедитесь, что выбран движок синтеза речи с установленным русским языковым пакетом.
