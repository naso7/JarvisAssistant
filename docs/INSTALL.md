# Инструкция по установке и сборке (J.A.R.V.I.S. Offline Assistant)

Данное руководство описывает два способа запуска ассистента на Android-смартфоне: быструю установку готовой сборки (из раздела Releases) и самостоятельную компиляцию C++ ядра из исходного кода.

---

## Системные требования для смартфона
* **ОС:** Android 8.0 (API 26) и выше.
* **Процессор:** 64-битный ARM (`arm64-v8a`).
* **Оперативная память:** минимум **4 ГБ ОЗУ** (рекомендуется 6+ ГБ).
* **Свободное место:** ~1.5 ГБ для хранения весов нейросетей.

---

## Способ 1. Быстрая установка (Без ПК и Android Studio)

1. Перейдите в раздел **[Releases](https://github.com)** данного репозитория и скачайте в папку «Загрузки» (Downloads) вашего смартфона 3 файла:
   * `JarvisAssistant-v1.0-arm64.apk` — установочный файл приложения.
   * `stt_model.bin` — модель распознавания речи (`whisper.cpp`).
   * `llm_model.gguf` — квантованная языковая модель (`Qwen2.5-1.5B-Instruct Q4_K_M`).
2. Установите скачанный `.apk` файл на телефон и запустите приложение **J.A.R.V.I.S.**.
3. Выдайте разрешение на использование **микрофона**.
4. При первом запуске программа автоматически определит отсутствие моделей и отобразит внизу экрана две кнопки импорта:
   * Нажмите **`ИМПОРТ STT (.bin)`** и выберите скачанный файл модели речи.
   * Нажмите **`ИМПОРТ LLM (.gguf)`** и выберите файл языковой модели.
5. Приложение самостоятельно скопирует и переименует файлы в защищенную системную директорию, после чего дуговой реактор загорится голубым светом.

*(Примечание: встроенный импорт поддерживает замену на любые другие совместимые модели форматов GGML/Whisper и GGUF — просто выберите новый файл через соответствующую кнопку).*

## Способ 2. Самостоятельная сборка из исходников (Android NDK)

### Требования к окружению:
* **IDE:** Android Studio (с поддержкой AGP 8/9+ и Kotlin 2.0+).
* **Инструменты (через SDK Manager):** Android NDK (`26.x` или `27.x`), CMake (`3.22.1+`).

### Этапы сборки:
1. Клонируйте репозиторий вместе с нативными библиотеками (`llama.cpp` и `whisper.cpp`):
   ```bash
   git clone --recursive https://github.com
   cd JarvisAssistant
   ```
2. Откройте проект в **Android Studio** и дождитесь синхронизации Gradle.
3. В меню **Build -> Select Build Variant...** переключите активную сборку модуля `:app` с `debug` на **`release`** (это активирует флаги компилятора `-O3 -DNDEBUG` и векторные инструкции ARM NEON, ускоряющие инференс в 10–15 раз).
4. Соберите APK (**Build -> Generate App Bundles or APKs -> Generate APKs**) или установите проект напрямую на смартфон (**Run `▶`**).

---

## Управление (Push-to-Talk)
* **Зажмите и удерживайте** палец на центре дугового реактора (индикатор станет красным).
* Произнесите команду (например: *«Джарвис, включи фонарик»*, *«Поставь таймер на 10 минут»*, *«Поставь будильник на 7:30»* или *«Открой Ютуб»*).
* **Отпустите палец** для запуска распознавания и генерации ответа.
